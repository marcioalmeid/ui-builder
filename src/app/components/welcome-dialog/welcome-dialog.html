Welcome to Task Template Builder

Build task forms in six steps: template → layout → data → rules → preview → publish.

  1. Choose a context and template in the sidebar
  2. Drag Fields onto the canvas
  3. Connect fields in the Data section
  4. Configure Rules for show/hide and events
  5. Preview (simulate operator to test rules)
  6. Publish and test at /run/:id

Try the pre-built New Task (Advertising) demo to see a full example.
