Welcome to Template Studio

Design a template, publish it, then operators create tasks from it.

  1. Set the template name and context in the toolbar
  2. Drag Fields onto the canvas
  3. Connect fields in the Data section (catalog sources: Users, Platforms, Vendors…)
  4. Configure Rules for show/hide and events
  5. Preview (simulate operator to test rules)
  6. Publish, then try a task from Tasks → New task
